## Key Design Decisions

- **Project-focused**: Entries highlight how concepts apply to dnachem-min specifically (macro-driven reactions, ScoreSpecies, TimeStepAction).
- **Implementation-grounded**: Gotchas section emphasizes non-obvious behavior visible only in `.cc` files (e.g., G-value NaN risk, molecule counter initialization).
- **Actionable**: Each topic includes concrete code examples or macro commands; readers can immediately apply knowledge.
- **Exhaustive gotchas**: Gotchas file is large (~500 lines) because Geant4-DNA has many subtle ordering constraints and silent failures.

## How to Use This KB

### Lookup Workflow
1. **For chemistry concepts**: Start in `chemistry-stage.md` (molecules, reactions, time-stepping).
2. **For physics model selection**: See `physics-lists.md` (which option for your energy range?).
3. **For user code**: Check `actions-and-scoring.md` (how to hook into the event loop).
4. **For geometry setup**: Refer to `geometry-world.md` (detector construction, materials).
5. **For gotchas**: Search `gotchas.md` by symptom (e.g., "NaN", "no chemistry", "hangs").

### Integration with /kb-query
When using `/kb-query` to ask questions like:
- "How do I set up time-stepping?" → Points to `chemistry-stage.md` and `physics-lists.md`.
- "What is G-value?" → Directs to `chemistry-stage.md` (ScoreSpecies section).
- "Why is my simulation hanging?" → Links to `gotchas.md` (Common Crash Patterns).
